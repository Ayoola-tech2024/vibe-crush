# ⚡ Vibe Crush — Match-3 Saga for @vibevibefun

A hyper-slick Candy Crush match-3 game built specifically for the **@vibevibefun** testnet bounty (`https://testnet.vibevibe.fun/vibe-vibers/for-raiders`).

## 🎮 Game Highlights
- **Real Viber Character Tiles**: Features authentic downloaded Viber portraits directly from the collection.
- **Candy Crush Mechanics with Web3 Twists**:
  - **Match-4**: Unlocks **Lightning Ray Vibers** that blast entire rows or columns with laser beams.
  - **Match-5**: Creates **Rainbow Vibe Supernovas** that wipe out all matching tiles of any chosen Viber.
  - **FUD Ice Obstacles**: Frozen tiles that must be cleared by adjacent matches before they can move.
- **5-Stage Saga Progression**: From beginner Raider to Grand Raider Master with Star ratings (1-3★).
- **Juicy Web Audio FX**: Zero-dependency procedural synth sounds for swaps, cascades, combos, explosions, and victory fanfares.
- **PFP Raider Vault**: Unlocking levels grants access to download and view exclusive Viber portraits.
- **Viral 1-Click X (Twitter) Sharing**: Directly shares formatted scores and victory achievements tagging `@vibevibefun` with `#VibeCrush`.
